# Output guidance

For quick mode, use a compact table of behaviors and evidence. For standard mode, use the three templates in `templates/`. For deep mode add a branch/state matrix and coverage assessment.

Minimum sections:
1. Scope, revision, assumptions and inspected paths
2. Observed behavior summary
3. Requirements with ID, conditions, outcomes, evidence, confidence
4. Call-chain/decision path
5. Edge/failure cases and configuration gates
6. Existing test evidence and proposed acceptance tests
7. Unknowns, gaps and inferred design intent (separately labeled)

Cite repository-relative paths with symbol and verified line range; include links only when a known repository URL is available. If no source is supplied, provide an investigation plan, not fabricated requirements.
